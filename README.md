Y-check — это десктопное приложение для Windows на платформе .NET/C#, предназначенное для поиска и анализа `.jar`-файлов Minecraft с целью выявления читов (hacked clients) и заблокированных модов. Приложение предоставляет два режима сканирования (папка и весь ПК), многоступенчатый алгоритм классификации каждого файла, встроенный просмотрщик байткода, а также источник загрузки файла через NTFS Alternate Data Streams.
